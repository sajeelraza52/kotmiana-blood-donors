Build a single-file blood donor directory website for a Pakistani village (Kotmiana) in Roman Urdu. Dark cinematic red theme, mobile-first, offline-safe system fonts. Hero with 🩸, title "Khoon Do, Zindagi Bachao", live stats (total donors, groups covered). Donor registration modal: name, blood group select (8 groups), Pakistani mobile number (normalize 03XX / +92 / 92 formats to 92...), contact preference radio (Call / WhatsApp / Both), area, last donation date. Donor cards show big blood-group badge, name, area, phone, and Call (tel:) / WhatsApp (wa.me with prefilled message) buttons matching the donor's chosen contact type. Filter chips per blood group with counts + search by name/area. Compatibility table (who can give to / receive from whom, all 8 groups). Eligibility cards (age 18-65, weight 50kg+, 3-month gap, healthy). Data in Firebase Realtime Database node "blooddonors" (public read/write) with localStorage demo fallback showing 3 sample donors. Own entries (tracked in localStorage) show a Delete button. Share button. Footer credits Sajeel Mods.
